# KS Expense Manager

> Part of the [KS-Suite](../README.md).

A minimalist, privacy-first personal finance and expense tracker. All data stays on the device.

| | |
|---|---|
| **Platform** | Android |
| **Tech stack** | Kotlin, Jetpack Compose, Room, Vico charts, DataStore |

## Getting started

```bash
git clone <repo-url> ks-expense-manager
cd ks-expense-manager
./gradlew assembleDebug
```

## Release

Releases are cut by pushing a semantic version tag (`git tag v1.2.3 && git push --tags`).
See the suite-level [CI/CD guide](../README.md#-cicd-semantic-versioning--automated-signing).
